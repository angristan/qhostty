# Qhostty

Qhostty is an early-stage Qt 6 port of [Ghostty](https://ghostty.org/) for Linux, focused on native KDE Plasma integration.

It reuses Ghostty's terminal core and renderer while replacing the GTK and libadwaita frontend with Qt. Qhostty is not usable yet.

See [PLAN.md](PLAN.md) for the implementation plan.

Qhostty is an independent project and is not affiliated with the official Ghostty project. It is available under the [MIT license](LICENSE).
